## PHASE 4 — Git Operations

### Step 4.1 — Create system/git_ops.py

Five functions, Python only, zero AI:
1. `init_repo()` — `git init` + initial commit if not already a repo
2. `get_diff_stat() -> str` — runs `git diff HEAD` (unstaged), returns `--stat` output
3. `get_full_diff() -> str` — runs `git diff HEAD`, returns full patch
4. `commit_step(step_n: int, task_name: str)` — `git add -A && git commit -m "Step {N}: {task_name} — approved"`
5. `revert_uncommitted()` — `git checkout -- . && git clean -fd` (reverts unstaged changes on failed step)

### Step 4.5.2 — Create system/agent_runner.py

Profile-driven, CLI-agnostic abstraction layer. Loads the active profile JSON and dispatches the correct subprocess with the correct flags per role. Python code should never hardcode "gemini" or "claude" — it should always call `agent_runner.run_role()`.

**Core API:**

#### `load_profile(profile_name: str) -> dict`
- Reads `system/profiles/{profile_name}.json`
- Returns parsed profile dict
- Raises `FileNotFoundError` with helpful message if profile doesn't exist

#### `run_role(role: str, prompt: str, session_id: Optional[str] = None, resume: bool = False, schema_json: Optional[str] = None, max_turns: int = 10) -> subprocess.CompletedProcess`
- Looks up `role` ("writer", "inspector", "reviewer") in the active profile
- Reads `tool`, `model`, `flags`, `tools` from the role config
- Dispatches the correct subprocess based on `tool`:
  - **gemini**: `subprocess.run(["gemini", *flags, prompt])` — adds `-r latest` for resume
  - **claude**: `subprocess.run(["claude", "-p", "--tools", tools_str, *flags, prompt])` — adds `--session-id` or `-r` for resume, `--json-schema` if provided
  - **ollama**: `subprocess.run(["ollama", "run", model], input=prompt, ...)` — stdin-based, no flags
- Appends to `brain/progress.txt`: `{ROLE}_CALLED` event
- Returns the `CompletedProcess` result

#### `get_prompt_template(role: str) -> str`
- Reads the prompt template path from the active profile's role config
- Loads `prompts/{prompt_template}` and returns the raw template string

#### Session refresh logic (called by `run_role("writer", ...)` before dispatching):
- Read `SESSION_MAX_TURNS` from env (default: 20)
- If `session_turn_count >= SESSION_MAX_TURNS`: `trigger_session_refresh(state)`
- If `REFRESH_ON_ARCH_SWITCH=true` and `current_arch_layer` changed: `trigger_session_refresh(state)`

#### `trigger_session_refresh(state)`:
- Calls `run_role("writer", ...)` with a `STATE.md` generation prompt
- Writes output to `brain/STATE.md`
- Resets `session_id` to `None` (forces new session next call)
- Resets `session_turn_count` to 0
- Appends to `brain/progress.txt`: `SESSION_REFRESH` event

## PHASE 5 — Nodes

### Step 5.1 — Rewrite system/nodes/gemini_node.py

**Logic:**
1. Read `current_task`, `last_error`, `step_number`, `gemini_session_id`, `session_turn_count`, `active_profile` from state.
2. Delete `workspace/gemini_output/reasoning.md` if it exists (stale cleanup).
3. Load the writer prompt template via `agent_runner.get_prompt_template("writer")`. Fill with `current_task` and `last_error`.
4. Call `agent_runner.run_role("writer", prompt, session_id=gemini_session_id)` (agent_runner handles all flags, `-r` flag, session refresh based on profile).
5. After first call completes, set `gemini_session_id = "latest"` in returned dict.
6. Parse JSON stdout. Extract `reasoning` field. Write to `workspace/gemini_output/reasoning.md`. If file exists but is stale (step 2 deleted it): create and write.
7. Verify `reasoning.md` exists and is non-empty; if missing, return `{"last_error": "reasoning.md not written", "loop_count": new_count}`.
8. Return `{"gemini_session_id": "latest", "loop_count": new_count, "session_turn_count": session_turn_count + 1}`.

**Error handling:** on any exception, return `{"last_error": str(e), "loop_count": new_count}` — do not crash the graph.

### Step 5.2 — Rewrite system/nodes/inspector_node.py

**Logic:**
1. Read `current_task`, `step_number`, `total_steps` from state.
2. Read `workspace/gemini_output/reasoning.md`.
3. Programmatic check (zero tokens): verify `reasoning.md` timestamp is newer than `current_task.md` — if not, immediately return `{"gpt_verdict": "INCOMPLETE: reasoning.md was not updated"}`.
4. Run `git_ops.get_diff_stat()` — get file manifest.
5. Read `brain/ENVIRONMENT_RULES.md`.
6. Load the inspector prompt template via `agent_runner.get_prompt_template("inspector")`. Fill with: `step_number`, `total_steps`, `current_task`, `reasoning_content`, `diff_stat`, `environment_rules`.
7. Call `agent_runner.run_role("inspector", brief)`.
8. Parse output — must start with one of: `PASS`, `INCOMPLETE:`, `QUESTION:`, `FAIL:`, `REVIEW_REQUESTED`.
9. Write verdict to `audit_trail/inspector_verdict.md`.
10. Return `{"gpt_verdict": verdict}`.

### Step 5.3 — Rewrite system/nodes/auditor_node.py

**Logic:**
1. Read `step_number`, `claude_session_id` from state; if `None`, generate a UUID and store it.
2. Read `workspace/gemini_output/reasoning.md` for context.
3. Python generates the full diff: `git_ops.get_full_diff()` — pass as text, Claude does not run git.
4. Load the reviewer prompt template via `agent_runner.get_prompt_template("reviewer")`. Fill with task description + reasoning summary + diff.
5. Define JSON schema for `--json-schema` flag:
   ```json
   {
     "type": "object",
     "required": ["severity", "issue", "why_it_matters", "suggested_fix"],
     "properties": {
       "severity": { "enum": ["CRITICAL", "MAJOR", "MINOR", "NONE"] },
       "issue": { "type": "string" },
       "why_it_matters": { "type": "string" },
       "suggested_fix": { "type": "string" }
     }
   }
   ```
6. Call `agent_runner.run_role("reviewer", prompt, session_id=claude_session_id, schema_json=schema_json, max_turns=10)` on first call; `resume=True`, `max_turns=5` on targeted fix call.
7. Parse JSON stdout → `claude_audit` dict.
8. Write `audit_trail/claude_audit_notes.md`.
9. Set `ceo_interrupt_flag = (claude_audit["severity"] == "CRITICAL")`.
10. Return `{"claude_audit": parsed, "claude_session_id": claude_session_id, "ceo_interrupt_flag": ...}`.

## PHASE 6 — Graph

### Step 6.1 — Rewrite system/graph.py

**Conditional edges:**

After `inspector_node`:
- `PASS` or `REVIEW_REQUESTED` → `auditor_node`
- `INCOMPLETE` or `FAIL`: → `gemini_node` (keep session, pass verdict as `last_error`)
- `QUESTION:` → `ceo_review` (interrupt)
- `loop_count >= 3` → `ceo_review` (infinite loop guard)

After `auditor_node`:
- `NONE` → `step_approved`
- `MINOR` or `MAJOR` → `gemini_node` (targeted fix, keep Claude session for follow-up review)
- `CRITICAL` → `ceo_review` (interrupt)

### step_approved_node:
1. Call `git_ops.commit_step(step_n, task_name)`.
2. Trigger `AGENTS.md` update: call `agent_runner.run_role("reviewer", ...)` with a targeted prompt asking Claude to append any new architectural learnings from this step to `brain/AGENTS.md` (use existing `claude_session_id`, `max_turns=3`, no json-schema — free-form append).
3. Call `reporter.build_reporter(state)`.
4. Archive status: copy `STATUS_UPDATE.md` → `status/step-{N}-summary.md`.
5. Increment `step_number`, reset `loop_count = 0`, `session_turn_count = 0`, clear `gemini_session_id = None` (new session per step), keep `claude_session_id` (Claude carries context across the run).
6. Load next task from `MASTER_PLAN.md`.
7. Append to `brain/progress.txt`: `STEP_APPROVED` event.
8. Return updates dict.
